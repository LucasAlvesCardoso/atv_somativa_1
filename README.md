# Encurtador API

API REST de encurtamento de URLs, escrita em Node.js com Express.

Projeto da disciplina de DevOps: a ideia e evoluir o mesmo repositorio ao longo
das semanas, comecando pelo versionamento e chegando ate a aplicacao rodando em
um container.

## Estado atual
